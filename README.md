# SEQUENCE

An interactive art desktop inspired by keygens and early internet release culture.

The application lives in [`cracktro-2003`](./cracktro-2003). The original folder name is retained so existing local commands and deployment paths continue to work.

```powershell
cd cracktro-2003
npm.cmd install
npm.cmd run dev
```

Open http://localhost:3000. See the [application guide](./cracktro-2003/README.md) for the project structure and how to add artwork.
